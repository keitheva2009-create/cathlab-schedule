# 心導管室排程系統 (Cath Lab Schedule)

單一 HTML 檔案的心導管室手術排程系統，取代原本共用的 Google 試算表。

> 本儲存庫另含 `order.html`「揪團點餐」系統，見下方說明。

## 特色

- **零安裝**：單一 `index.html`，用 Chrome / Edge 直接開啟即可使用
- **Dropbox 同步**：排程資料存在一個 JSON 檔（透過 File System Access API 讀寫），放在 Dropbox 共享資料夾即可多台電腦同步（每 4 秒自動偵測更新）
- **版面比照原試算表**：兩間導管室並排（Philip / SIEMENS），每日 8:00–12:00、13:00–17:00 各半小時時段＋加台1–4
- **手術計時**：一鍵蓋「手術開始／結束」時間戳，進行中的台以紅底閃爍標示
- **劃線取消**：取消的排程以刪去線保留原格，可復原；時段可再排他人
- **Excel 匯入**：直接讀取從 Google 試算表下載的 .xlsx（自製解析器，無外部函式庫），自動辨識日期／時段／欄位／合併儲存格，匯入前逐筆預覽
- **下拉選單可維護**：術式、醫師、床號/醫院、細項清單可在設定中編輯，新值自動學習
- **列印**：A4 橫向列印當週排程

## 使用方式

1. 下載 `index.html` 與 `使用說明.txt`，放到 Dropbox 內的資料夾（例如 `心導管排程`）
2. 用 Chrome 或 Edge 開啟 `index.html`，第一次點「建立新資料檔…」並將資料檔存在同一資料夾
3. 其他電腦同步後開啟同一份 `index.html`，點「開啟現有資料檔…」選同一個 JSON

詳細操作見 `使用說明.txt`。

## 揪團點餐（order.html）

取代 LINE 群組「複製上一個人的訊息再貼上」的接龍點餐方式。單一 `order.html`，與排程系統共用同一個 Firebase 雲端資料庫（資料放在 `teams/{金鑰}/meta/food` 等路徑，與排程互不干擾）。

### 功能

- **發起訂餐**：輸入店名、截止時間，可拍照上傳菜單（自動壓縮，最多 6 張），產生專屬連結貼到 LINE 群組
- **截止倒數**：頁面顯示結單時間與倒數計時，剩 10 分鐘閃紅提醒，時間到自動停止收單
- **進入先輸入名字**：每筆訂餐都空白重填，不會把發起人或共用電腦上一位的名字帶進來（同一筆訂餐、同一支手機會記住自己填過的名字）
- **三種點餐方式**：
  1. 「跟他點一樣」— 整份複製某個人點的所有品項
  2. 「+1 改備註」— 跟他點同品項，但自己改甜度冰塊等備註
  3. 自由輸入新品項（品項＋備註）；要幫別人點就用「更改」切換名字
- **即時同步**：大家點的內容立即出現在所有人畫面上（目前訂單就在菜單下方）；只能編輯／刪除自己這台裝置加入的品項（發起人可管理全部）
- **彙總（發起人限定）**：自動按品項＋備註分組統計（打電話訂餐用），一鍵複製彙總文字或 LINE 接龍文字；分享出去的連結固定是點餐者畫面（帶 `&v=m`），任何人——包含發起人自己——點開都不會出現彙總或管理功能，發起人從首頁「最近的訂餐」進入才是管理畫面
- **發起人管理**：修改截止時間、立即截單、延長 30 分鐘、刪除整筆訂餐

### 使用方式

1. 把 `order.html` 放上任一靜態網站空間（例如開啟本儲存庫的 GitHub Pages），取得網址
2. 發起人開啟網址 → 填店名與截止時間、上傳菜單照片 → 建立訂餐 → 按「複製連結」或「傳到 LINE」貼到群組
3. 同事點開連結 → 輸入名字 → 看菜單點餐（可跟單、可自由輸入）
4. 時間到自動截止，發起人按「複製彙總文字」即可打電話訂餐

（連結需要大家的手機都能開啟，所以請用網址部署；不適合像排程系統那樣用 file:// 開啟。）

## 注意

- **本儲存庫不含任何排程／病人資料**——資料檔（`心導管排程資料.json`）只存在於使用者的 Dropbox，請勿上傳
- 多人協作採「最後儲存者為準」，Dropbox 版本紀錄可作為還原備援
- 需要 Chromium 系瀏覽器（Chrome / Edge）以支援 File System Access API
